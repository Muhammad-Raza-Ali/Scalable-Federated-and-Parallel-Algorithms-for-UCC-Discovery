# Scalable-Federated-and-Parallel-Algorithms-for-UCC-Discovery

Scalable Federated and Parallel Algorithms for Unique Column Combination Discovery.

## Overview
This project focuses on designing a scalable architecture that integrates **federated processing** and **parallel computation (Client × Core)** to accelerate enumeration algorithms for data profiling.

## Objective
The main objective is to efficiently discover **Unique Column Combinations (UCCs)** in large and distributed datasets by combining:
- **Federated processing** across multiple nodes or clients
- **Parallel computation** within each node using multi-core execution

## Research Focus
The project investigates how minimal hitting set discovery and UCC enumeration can be improved through:
- Distributed data processing without full centralization
- Parallel exploration of the search space
- Scalable aggregation of intermediate results
- Efficient runtime and task management for large datasets

## Expected Outcome
The expected outcome is a scalable system for UCC discovery that improves performance while preserving correctness in federated and distributed environments.
